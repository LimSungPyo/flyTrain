# 뇌 설계

> 목표: 커넥톰을 연출이 아니라 **실제 판단과 학습**에 최대한 쓴다.
> 상태: 초안 (2026-10-09). Phase 0 검증 결과에 따라 고친다. 게임용 가정은 **[가정]**으로 표시한다.

## 1. 출발점

- **FlyWire 커넥톰** (Dorkenwald et al., 2024, *Nature*): 성체 초파리 뇌 전체, 뉴런 약 14만 개, 시냅스 약 5천만 개. 뉴런 간 시냅스 수와 신경전달물질 예측(흥분/억제)을 제공한다.
- **세포 유형 분류** (Schlegel et al., 2024, *Nature*): 뉴런마다 `KC`, `MBON`, `LPLC2` 같은 유형 이름이 붙어 있다. 회로를 고를 때 이 이름을 쓴다.
- **전뇌 LIF 모델** (Shiu et al., 2024, *Nature*): 커넥톰을 그대로 LIF(누설 적분-발화) 뉴런망으로 돌려 실제 감각→운동 반응을 예측했다. 시냅스 가중치 = 시냅스 수 × 부호(흥분/억제) × 상수라는 단순한 규칙이다. 우리 엔진의 기준 모델이다.

배선도만으로는 "학습된 AI"가 아니다. 그래서 **배선은 커넥톰 그대로 두고, 학습은 실제 초파리가 학습하는 자리(버섯체)에서만 일어나게** 한다.

## 2. 전체 구조

```
게임 관측 ──▶ 감각 인코딩 ──▶ [커넥톰 하위 회로 LIF 시뮬레이션] ──▶ 행동 읽기 ──▶ 게임 행동
                (PN·시각 뉴런 자극)        │                          (MBON·DN 발화율)
                                         ▼
                                  버섯체 KC→MBON 가소성 ◀── 보상(PAM 도파민 뉴런 자극)
```

### 하위 회로

전뇌 14만 개를 매번 돌리면 느리다. 종목에 필요한 경로만 잘라 쓴다(수천~수만 개).

| 회로 | 쓰는 곳 | 주요 세포 유형 |
|---|---|---|
| 후각 → 버섯체 | 학습·패턴 기억 (가위바위보, 종 치기) | 투사 뉴런 `PN` → `KC` → `MBON`, 도파민 `PAM`/`PPL1` |
| 시각 탈출 | 반응속도 (킥복싱 회피, 종 치기) | `LPLC2` → `DNp01`(자이언트 파이버) |
| 하강 뉴런 | 운동 출력 (킥복싱) | `DN*` 계열 |

- 하위 회로는 `back_end/connectome/` 스크립트가 원본에서 추출해 `data/processed/`에 저장한다(희소 행렬 + 뉴런 메타데이터).
- 경계에서 잘린 입력은 상수 배경 입력으로 대체한다 **[가정]**.

## 3. 학습 — 버섯체

실제 초파리의 연합 학습 방식을 그대로 쓴다.

1. 게임 상황(예: 상대의 직전 수)을 **냄새처럼** `PN` 자극 패턴으로 인코딩한다 **[가정: 게임 상황 → 사구체 매핑은 임의 고정]**.
2. `PN → KC` 연결은 **커넥톰 그대로**다. 그래서 상황마다 서로 다른 소수의 KC가 켜진다(희소 부호화).
3. `MBON` 그룹을 행동 후보에 대응시킨다(예: 가위/바위/보) **[가정]**. 발화율이 가장 높은 그룹의 행동을 고른다.
4. 결과가 좋으면 보상 `PAM`, 나쁘면 벌 `PPL1` 도파민 뉴런을 자극한다. **그 순간 켜져 있던 KC → 해당 MBON 연결 가중치**를 바꾼다. 이것이 학습이다.
5. 학습률은 `intelligence` 스탯이 정한다.

### 영구 저장 (기억 고정)

- 초파리마다 **KC→MBON 가중치 변화량**만 따로 저장한다(전체 배선은 모두 같은 커넥톰).
- 경기 중 변화의 일부만 경기 후 영구 가중치에 더한다(비율은 GAME_DESIGN 미정 사항 2).
- 저장 크기: KC 수천 × MBON 수십 규모라 초파리 한 마리당 수백 KB 이하로 예상한다 **[추정]**.

## 4. 스탯 → 회로 파라미터

| 스탯 | 바꾸는 것 |
|---|---|
| 힘 | 운동 DN 출력 → 게임 데미지 변환 계수 |
| 민첩 | 보행 DN 출력 문턱 낮춤, 행동 쿨다운 감소 |
| 반응속도 | `LPLC2` 경로 시냅스 이득 증가 → 첫 발화까지 걸리는 시간 단축 |
| 지능 | KC→MBON 학습률 |
| 지구력 | 발화 적응(피로) 시간 상수 |
| 운 | 막전위 노이즈 크기 (상한 있음) |

모든 변화는 배선을 바꾸지 않고 **이득·문턱·상수만** 바꾼다. 같은 스탯이면 같은 뇌다.

## 5. 성능 목표

- 한 번의 판단 = 시뮬레이션 시간 약 100ms. 시간 간격 0.1~0.5ms.
- numpy/scipy 희소 행렬 곱으로 시작하고, 느리면 PyTorch(GPU)로 옮긴다.
- 목표: 5라운드 한 경기를 서버에서 **수 초 안**에 끝낸다. Phase 0에서 측정한다.

## 6. Phase 0에서 검증할 것

1. 원본을 불러와 Shiu 모델의 대표 결과(당 감지 뉴런 자극 → 먹이 행동 하강뉴런 발화)를 재현한다.
2. `PN → KC → MBON` 하위 회로를 잘라 돌리고, 보상 학습으로 **가위바위보 패턴 상대(예: 항상 바위)를 몇 라운드 안에 이기는지** 확인한다.
3. `intelligence`를 바꾸면 학습 속도가 측정 가능하게 달라지는지 확인한다.
4. 판단 1회 소요 시간을 잰다.
