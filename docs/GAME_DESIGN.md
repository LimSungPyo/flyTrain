# 게임 설계

> 상태: 초안 (2026-10-09). 확정된 것과 미정인 것을 구분해 적는다. 미정 사항은 맨 아래에 모은다.

## 1. 한 줄 콘셉트

**진짜 초파리 뇌지도로 만든 내 초파리를 키워서, 남의 초파리를 바보 같은 종목으로 이기는 예능 RPG.**

- 플레이어는 직접 조작하지 않는다. **트레이너**로서 초파리를 만들고, 경기를 지켜보며, 라운드 사이에 포인트를 주고 잔소리(코칭)를 한다.
- 초파리는 실제 FlyWire 커넥톰 기반의 뇌로 스스로 판단하고, 보상을 받으면 진짜 학습 회로(버섯체)의 연결이 바뀐다.
- 목표 감정: "얘가 왜 저래 ㅋㅋㅋ" → "어? 배웠네?" → "내 파리 천재인데?"

## 2. 핵심 루프

```
초파리 생성(스탯 20pt + 커스텀)
   ↓
로비 ── 랭크전(자동 매칭) / 다른 초파리 프로필에서 직접 도전
   ↓
미니게임 선택 → 5라운드 경기
   │  라운드 시뮬레이션(서버) → 리플레이 시청 → 라운드 포인트 5pt 배분 + 코칭 → 다음 라운드
   ↓
결과: 레이팅 변동, 경험치, 기억 고정(뇌 일부 영구 변화)
   ↓
로비 (경기 중 받은 포인트는 리셋)
```

## 3. 스탯

| 스탯 | 키 | 게임 효과 | 연결된 뇌 회로 (자세히는 BRAIN.md) |
|---|---|---|---|
| 힘 | `strength` | 타격 데미지, 밀어내기 | 운동 하강뉴런(DN) 출력 증폭 |
| 민첩 | `agility` | 회피, 행동 속도 | 보행·비행 관련 DN |
| 반응속도 | `reflex` | 선제 행동, 종 치기 | 시각 탈출 회로(LPLC2 → 자이언트 파이버) |
| 지능 | `intelligence` | 상대 패턴 학습 속도 | 버섯체 KC→MBON 가소성 학습률 |
| 지구력 | `stamina` | 후반 라운드 성능 유지 | 뉴런 적응·피로 상수 |
| 운 | `luck` | 변수 | 시뮬레이션 노이즈 (상한 있음) |

- 생성 포인트: **20** (레벨 보너스 추가 가능)
- 라운드 포인트: 라운드 1~4가 끝날 때마다 **5** → 경기당 최대 +20, 그 경기에서만 유효
- 스탯 상한: **30** (경기 중 포인트 포함). 수확 체감 곡선은 Phase 1에서 정한다.
- 코드: `back_end/brain/stats.py`

## 4. 영구 성장 (확정: 넣는다)

경기 안 포인트는 리셋되지만, 아래 두 가지는 남는다.

1. **기억 고정** — 경기 중 버섯체에서 바뀐 연결의 일부(예: 20%)가 그 초파리의 뇌에 영구 저장된다. 실제 초파리의 장기기억 고정에서 따온 설정이다. 많이 싸운 초파리일수록 진짜로 "경험 많은 뇌"가 된다.
2. **레벨** — 경기 경험치로 레벨이 오르고, 레벨마다 생성 포인트 보너스를 받는다(스탯 재배분 가능 여부는 미정).

## 5. 미니게임 (초기 3종)

| 종목 | 키 | 주요 스탯 | 뇌가 하는 일 | 웃음 포인트 |
|---|---|---|---|---|
| 가위바위보 | `rps` | 지능, 운 | 상대의 직전 수를 "냄새"(PN 자극)로 맡고 버섯체로 패턴 학습 | 질 때마다 같은 수를 고집하다 갑자기 깨달음 |
| 킥복싱 | `kickbox` | 힘, 민첩, 지구력 | 접근·회피 자극 → DN 출력으로 펀치·킥·회피 | 날개로 따귀, KO 시 발라당 뒤집혀 다리 버둥 |
| 과일 종 치기 | `bell` | 반응속도, 지능 | 과일 카드 시각 자극 → 같은 과일 5개면 종 치기 | 과일 냄새에 정신 팔려 종 대신 바나나로 돌진 |

- "할리갈리"는 상표이므로 게임 안에서는 **과일 종 치기**로 부른다.
- 종목은 `back_end/games/`에 `MiniGame` 플러그인으로 추가한다.

## 6. 대전 방식 (확정: 비동기)

- **랭크전**: 버튼을 누르면 레이팅·티어와 전투력(스탯 합 + 레벨)이 비슷한 다른 초파리와 자동 매칭한다.
- **직접 도전**: 랭킹이나 프로필에서 상대 초파리를 눌러 도전을 신청한다.
- 상대는 접속해 있을 필요가 없다. 그 시점 초파리의 **스냅샷(고스트)**과 싸운다. 상대의 라운드 포인트는 상대가 정해 둔 **자동 배분 성향**(예: 힘몰빵, 균형형, 도박형)으로 배분한다.
- 레이팅: **Glicko-2**. 티어는 레이팅 구간으로 나눈다.

### 티어 (이름 초안)

구더기 → 번데기 → 날파리 → 초파리 → 과일 사냥꾼 → 바나나 군주 → 썩은 사과의 신

## 7. 예능 장치

- **파리 중계진(Claude)** — 리플레이 기록을 보고 캐스터·해설 2인 체제로 과장된 중계를 만든다. "아~ 이 파리, 3라운드째 바위만 냅니다! 철학이 있어요!"
- **뇌 CT 하이라이트** — 결정적인 순간에 실제로 많이 발화한 세포 유형을 띄운다. "이 순간 공포 뉴런(LPLC2) 214개 동시 발화!"
- **코칭 잔소리** — 트레이너가 자연어로 지시하면 초파리가 성격대로 반응한다("싫은데요" 출력 가능). 실제 효과는 정해진 범위의 파라미터 조정이다.
- **커스터마이징** — 몸 색, 눈 색, 날개 무늬, 콧수염, 선글라스, 왕관, 머리띠 같은 쓸데없이 진지한 액세서리.
- **초파리 이름 생성기** — 생성 시 스탯과 외모를 보고 Claude가 이름과 한 줄 소개를 지어 준다.
- **하이라이트 공유** — 웃긴 장면을 짧은 클립으로 내보낸다(후순위).
